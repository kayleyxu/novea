# Novea — PRL Prescription Tool

Map the patient's scotoma with a digital Amsler grid, then compute the optimal Preferred Retinal Locus for MS or eccentric viewing correction.

## How to use

1. Click the **Start with Patient Scan** button.
2. Click **BEGIN TEST - RIGHT EYE**.
3. Under **DRAWING MODE**, select a mode to mark the different areas:
   - **BOUNDARY TRACE**
   - **PAINT SCOTOMA**
   - **DISTORTION**
4. Select **GENERATE DAMAGE MAP**.
5. Repeat steps 2–4 for the left eye.
6. Click **Generate Prescription**.

A **Load Demo** button loads built-in demo patients for both eyes.

## Running

Open `index.html` in a modern browser.
